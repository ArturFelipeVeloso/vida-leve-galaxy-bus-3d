# Vida Leve · Galaxy Bus 9090 em 3D

Modelo 3D interativo do ônibus double decker Galaxy Bus 9090 da Vida Leve, feito em WebGL puro (sem bibliotecas), em um único arquivo `index.html`.

**Ver online:** https://arturfelipeveloso.github.io/vida-leve-galaxy-bus-3d/

- Arraste para girar, role ou pince para aproximar
- Vistas prontas: 3/4, frente, laterais, traseira e aérea
- Botão "Na estrada": rodas girando e pista em movimento
